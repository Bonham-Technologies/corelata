Sample output

One run, as Corelata delivered it.

Everything below is the product's own output from one run, with nothing rewritten: the exported report, what corelata trace prints about the run and about one claim, and the auditor's findings as the API returns them (filtered to the failed verdicts and indented).

The run used Corelata 0.1.8 with its synthetic test model, a deterministic stand-in that ships with Corelata for tests and demonstrations. No language model is involved, so the prose is placeholder text: a real model writes the assessment itself. The pipeline, the checks, the revision loop, the exports and the trace are the real ones.

The second source ends with UNSOURCED, a marker that tells the synthetic writer to add a claim with no evidence, so that the auditor has something to find.

Input

Two sources and a value statement

varna-port.txt, the sample source in Corelata's bundle

The port of Varna expanded its container capacity in 2025.

Capacity expansion was financed by a state bank.

Container traffic through Varna rose 40 percent.

trade-note.txt

A trade newsletter repeats, without naming a source, that the terminal will reach full capacity early. UNSOURCED

Value statement

The port of Varna's 2025 container expansion, financed by a state bank, is already raising traffic; shippers and the port authority should plan for higher volumes.
