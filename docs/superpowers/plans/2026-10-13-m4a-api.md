# Corelata M4a: REST API — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver spec §14 M4a: the `corelata_api` FastAPI package with every route in spec §10.1 (projects, sources incl. the Coglossa fetch, discoveries, runs with SSE progress, cancel and review, report and trace views, packs, doctor), `none`/`trusted_header` auth, a committed `schema/openapi.json` with a drift test, route tests against the fake model and a real Postgres — plus the three M3 follow-ups assigned to M4a (a queue failure marks the run failed; a periodic sweep fails runs whose job vanished; uploads parse off the event loop).

**Architecture:** The API is a thin shell over `corelata.service` (M3): one `ApiContext` (config, database, storage, prompts, job queue, optional Coglossa client) built in the app lifespan and injected into routes; every `/api` route except `/api/health` requires `current_user`; engine exceptions map to HTTP statuses in one table; SSE polls `service.run_progress` at `api.progress_poll_s`; reports are served from the worker's stored export rows (spec §8.4 invariant 5) and re-rendered only when claim ids are requested; the API never calls a model except through `/api/system/doctor`. The shell (`app.py`, `context.py`, `auth.py`, `errors.py`, `web.py`, `openapi.py`, `main.py`, the test harness) is copied from Coglossa's `api/coglossa_api` (spec §4.3) with the product name parameterised; Coglossa's translation routes are replaced by Corelata's. Read models the API returns live in the engine (`corelata.schema`, `corelata.trace`, `corelata.standards.loader`) so the CLI and the web share one contract.

**Tech Stack:** Python 3.12, uv (one project per directory, `api/` depends on `../engine` as an editable path source), FastAPI `>=0.115,<1`, uvicorn, python-multipart, httpx (ASGI transport in tests; client for the Coglossa fetch), pytest + pytest-asyncio against a real Postgres 16 (`CORELATA_TEST_DATABASE_URL`, the engine's pytest plugin).

**Spec:** `docs/superpowers/specs/2026-10-12-corelata-v1-design.md` — §4.2 (layout: `api/` package `corelata_api`, `schema/openapi.json`), §4.3 (copy-from-Coglossa rule), §5.3 (Coglossa fetch when `integrations.coglossa` is configured), §7.1 (discovery), §7.2 (state machine), §8.4 (invariant 5), §9 (`with_claim_ids`), §10.1 (routes, auth, openapi.json), §10.3 (what the web screens need from the API), §11 (`api`, `auth`, `integrations` sections), §13 (real Postgres, 95% gate), §14 (M4a row). M3 follow-ups assigned to M4a: `docs/m3-followups.md` ("Should fix soon": `add_source` in a thread; `review_run`/`start_run` not atomic with the queue → mark failed on defer failure + sweep; widen the sweep to any non-terminal run whose job is neither `todo` nor `doing`; "Later": the route → service mapping). ## Global Constraints

- Python `>=3.12`; `uv` for everything. The new `api/` project's runtime dependencies are exactly: `corelata` (editable path source `../engine`), `fastapi>=0.115,<1`, `uvicorn>=0.32,<1`, `python-multipart>=0.0.18`. Dev group: `pytest>=8.3`, `pytest-asyncio>=0.24`, `pytest-cov>=5.0`, `ruff>=0.7`. `httpx` and `pyyaml` arrive through the engine. The engine gains **no** new runtime dependency.
- Both packages run `pytest` with `--cov-branch --cov-fail-under=95` and `filterwarnings = error`; every task leaves both suites green at or above 95% and `uv run ruff check .` / `uv run ruff format --check .` clean in the package it touches (line length 100, rules E F I B UP SIM).
- Tests use a real Postgres (spec §13) through `corelata.testing.pytest_db`; a missing `CORELATA_TEST_DATABASE_URL` fails, never skips. CI gets an `api` job with the same Postgres service as the engine job (Task 4).
- Every route lives under `/api`. `GET /api/health` is the only route without `current_user`; every other route, including `GET /api/openapi.json`, is in a router with `dependencies=[Depends(current_user)]`. FastAPI's built-in `/docs`, `/redoc` and `/openapi.json` are disabled (Swagger UI loads from a CDN: blank on an air-gapped site).
- Error bodies are `{"detail": "<one line>"}`; FastAPI's own 422 validation errors keep their default list-shaped `detail`. Internal errors answer `500 {"detail": "internal error"}` and are logged with the traceback; no exception text other than the mapped ones reaches a client.
- The API never calls a model except `GET /api/system/doctor`; it never imports `corelata.worker.execute` (tests may); it imports `corelata.worker.app` only for `open_app`/`ProcrastinateQueue`.
- Parsing an upload, rendering a report and reading a stored export run off the event loop (`asyncio.to_thread`).
- No CORS, no middleware, no request ids: the SPA is same-origin and a reverse proxy authenticates (spec §10.1). Static files, when `api.web_dir` is set, are served without auth.
- Product name parameterised (spec §4.3): package `corelata_api`, distribution `corelata-api`, script `corelata-api`, title `Corelata`, env `CORELATA_CONFIG` / `CORELATA_DATABASE_URL` / `CORELATA_TEST_DATABASE_URL`, logger `corelata.api`, test base URL `http://corelata.test`.
- Every intentional change to a copied module is recorded in `docs/m4a-followups.md` under **Divergences from Coglossa** with a one-line reason; improvements Coglossa should take are tagged **backport** (Task 11 writes the file; earlier tasks note what to record in their reports).
- The library/database boundary (`engine/tests/test_boundary.py`) holds: the new `corelata.integrations.coglossa` imports no database module; `corelata.worker.sweep` is under `corelata.worker` and may.
- `RunRecord.schema_version` stays `"1"`; no trace field changes in this milestone.
- Commits: conventional prefix (`feat:`, `test:`, `docs:`, `build:`, `fix:`), one task per commit unless a step says otherwise, ending with the attribution lines the session supplies. `schema/openapi.json` is regenerated (`make schema` at the repository root, or `cd api && uv run python -m corelata_api.openapi ../schema/openapi.json`) and committed in every task that adds or changes a route or a response model, because `api/tests/test_openapi.py` (Task 5) fails otherwise.

## Review Focus

1. **An upload over `api.max_upload_mb`** answers 413 with the limit in the message and leaves nothing in storage; a zero-byte file answers 422 (`x.txt is empty`); a `.png` answers 422 (`unsupported file type`); a multipart request without a file answers 422. (Task 6: `test_upload_too_large_leaves_no_file`, `test_upload_rejections`.)
2. **An SSE client that disconnects mid-run** stops the poll loop (the generator is closed by the server; no stray polling), and a run that finishes while nobody listens gives the next client one terminal event and a closed stream; the stream also ends on a deleted run and on a database outage (the browser reconnects after `retry:`). (Task 8: `test_a_finished_run_sends_one_event`, `test_changes_are_streamed_until_the_run_ends`, `test_a_deleted_run_ends_the_stream`, `test_a_database_error_ends_the_stream`.)
3. **A report requested for a run without one** (running, `gate_rejected`, `failed`, `cancelled`) answers 409 naming the state; a DOCX requested when the worker's DOCX export failed answers 409 with `export_error`; a claim id that is not in the report answers 404; `with_claim_ids=1` re-renders from the stored record and shows the ids, while `with_claim_ids=0` serves the stored bytes unchanged (same sha256 as the export row). (Task 10: `test_report_before_completion_is_409`, `test_report_docx_export_error_is_409`, `test_unknown_claim_is_404`, `test_stored_report_bytes_match_the_export_row`, `test_claim_ids_re_render`.)
4. **`auth.mode: trusted_header` with the header missing, empty or whitespace** answers 401 naming the header; a value with surrounding spaces is trimmed and becomes the review event's `actor`. (Task 4: `test_trusted_header_required_on_every_route`, `test_trusted_header_user_is_trimmed`; Task 8: `test_review_records_the_actor`.)
5. **A queue outage at `POST /api/runs`** leaves the run row `failed` with `could not queue the run: …` and answers 503 (the job queue is the database); a run whose job vanished (queue outage after the row committed, or its job `failed` outside the run) is marked `failed` by the worker's sweep within one minute, and a run whose job is `todo` or `doing` is never touched. (Task 2: `test_a_queue_failure_marks_the_run_failed`; Task 3: `test_sweep_fails_runs_without_a_job`, `test_sweep_leaves_queued_and_running_jobs_alone`.)

```python
class ProfileSummary(BaseModel):
    name: str
    draft: bool
    tone: str


class PackSummary(BaseModel):
    """One entry of `GET /api/packs` (spec §10.1): a pack directory as found, built-in packs
    included. `name` is the directory name, which is what `load_pack` takes."""

    name: str
    version: str
    extends: str | None
    description: str
    builtin: bool
    profiles: list[ProfileSummary]
    error: str | None = None  # the directory does not load as a pack; the message says why


def _summary(path: Path, builtin: bool) -> PackSummary:
    try:
        raw = read_pack_dir(path)
    except PackError as e:
        return PackSummary(
            name=path.name,
            version="",
            extends=None,
            description="",
            builtin=builtin,
            profiles=[],
            error=str(e),
        )
    return PackSummary(
        name=path.name,
        version=raw.meta.version,
        extends=raw.meta.extends,
        description=raw.meta.description,
        builtin=builtin,
        profiles=[
            ProfileSummary(name=p.name, draft=p.draft, tone=p.tone) for p in raw.profiles.values()
        ],
    )


def list_packs(packs_dir: Path | None) -> list[PackSummary]:
    """Every directory with a pack.yaml in `packs_dir` and the built-in directory, by name. A
    customer pack shadows a built-in one of the same name (as `find_pack_dir` resolves it). A
    directory that does not load is listed with its error, so an operator sees it instead of a
    missing entry."""
    found: dict[str, PackSummary] = {}
    for base, builtin in ((BUILTIN_PACKS_DIR, True), (packs_dir, False)):
        if base is None or not base.is_dir():
            continue
        for path in sorted(p for p in base.iterdir() if (p / "pack.yaml").is_file()):
            found[path.name] = _summary(path, builtin)
    return [found[name] for name in sorted(found)]
```

`BaseModel` is already imported in `loader.py` (used by `_model`); if `Path` is not, add `from pathlib import Path`.

```python
def run_trace(record: RunRecord) -> RunTrace:
    steps: list[DraftStep] = []
    prev: ReportBody | None = None
    for draft in record.drafts:
        changes = None if prev is None else draft_changes(prev, draft.report)
        steps.append(DraftStep(role=draft.role, iteration=draft.iteration, changes=changes))
        prev = draft.report
    calls = [
        CallSummary.model_validate(c.model_dump(exclude={"request", "response"}))
        for c in record.llm_calls
    ]
    return RunTrace(summary=summarize(record), drafts=steps, calls=calls)
```

```python
"""Runs and discoveries whose job is gone (spec §7.5; M3 follow-up). A row commits before its
job is queued, and a job can end `failed` outside the run (database retries exhausted mid-run);
either way the row would sit non-terminal forever. The worker sweeps them every minute."""

import logging
import uuid
from datetime import timedelta

from sqlalchemy import bindparam, text, update

from corelata.schema import TERMINAL_STATES, DiscoveryState, RunState
from corelata.store.db import Database
from corelata.store.models import Discovery, Run, utcnow

log = logging.getLogger("corelata.worker")

ORPHAN_GRACE_S = 120.0  # longer than any request that commits a row and then queues its job
ORPHAN_ERROR = (
    "no queued job exists for this {what}: the queue was unavailable when it was created, or "
    "its job failed outside the run; start it again"
)

# Rows past the grace period with no job that is waiting (todo) or executing (doing).
_ORPHAN_RUNS = text(
    "SELECT r.id FROM run r WHERE r.state NOT IN :terminal AND r.created_at < :before "
    "AND NOT EXISTS (SELECT 1 FROM procrastinate_jobs j WHERE j.args->>'run_id' = r.id::text "
    "AND j.status IN ('todo', 'doing')) FOR UPDATE SKIP LOCKED"
).bindparams(bindparam("terminal", expanding=True))
_ORPHAN_DISCOVERIES = text(
    "SELECT d.id FROM discovery d WHERE d.state IN ('created', 'running') "
    "AND d.created_at < :before AND NOT EXISTS (SELECT 1 FROM procrastinate_jobs j "
    "WHERE j.args->>'discovery_id' = d.id::text AND j.status IN ('todo', 'doing')) "
    "FOR UPDATE SKIP LOCKED"
)


async def sweep_orphans(
    db: Database, *, grace_s: float
) -> tuple[list[uuid.UUID], list[uuid.UUID]]:
    """Mark such runs and discoveries `failed`; returns the ids it changed."""
    before = utcnow() - timedelta(seconds=grace_s)
    terminal = [state.value for state in TERMINAL_STATES]
    async with db.session() as s, s.begin():
        run_ids = list(await s.scalars(_ORPHAN_RUNS, {"terminal": terminal, "before": before}))
        if run_ids:
            await s.execute(
                update(Run)
                .where(Run.id.in_(run_ids))
                .values(
                    state=RunState.FAILED.value,
                    error=ORPHAN_ERROR.format(what="run"),
                    finished_at=utcnow(),
                )
            )
        discovery_ids = list(await s.scalars(_ORPHAN_DISCOVERIES, {"before": before}))
        if discovery_ids:
            await s.execute(
                update(Discovery)
                .where(Discovery.id.in_(discovery_ids))
                .values(
                    state=DiscoveryState.FAILED.value,
                    error=ORPHAN_ERROR.format(what="discovery"),
                    finished_at=utcnow(),
                )
            )
    for run_id in run_ids:
        log.warning("run %s had no job; marked failed", run_id, extra={"run_id": str(run_id)})
    for discovery_id in discovery_ids:
        log.warning(
            "discovery %s had no job; marked failed",
            discovery_id,
            extra={"discovery_id": str(discovery_id)},
        )
    return run_ids, discovery_ids
```

If `TERMINAL_STATES` or `DiscoveryState` is not exported from `corelata.schema`, import from `corelata.schema.run` / `corelata.schema.progress`. If `Run.created_at` is stored without a time zone, compare against `utcnow().replace(tzinfo=None)`; check `store/models.py` (`utcnow`) and keep the comparison consistent with how M3 stores timestamps.

```python
"""Engine exceptions → HTTP statuses, in one table; the body is always {"detail": "<one line>"}.
Copied from Coglossa with Corelata's exception types."""

import logging
from collections.abc import Awaitable, Callable

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from sqlalchemy.exc import InterfaceError, OperationalError

from corelata.config import ConfigError
from corelata.ingest.base import IngestError
from corelata.service import ConflictError, InvalidRequestError
from corelata.standards.loader import PackError
from corelata.storage import StorageError
from corelata.store.db import error_reason
from corelata.store.runs import NotFoundError
from corelata.trace import TraceError

log = logging.getLogger("corelata.api")

Handler = Callable[[Request, Exception], Awaitable[JSONResponse]]


class UploadTooLargeError(Exception):
    """The upload is larger than api.max_upload_mb (HTTP 413)."""


_STATUS: tuple[tuple[type[Exception], int], ...] = (
    (NotFoundError, 404),
    (TraceError, 404),  # a claim id the report does not have
    (ConflictError, 409),  # includes InvalidRunStateError
    (UploadTooLargeError, 413),
    (InvalidRequestError, 422),
    (IngestError, 422),
    (PackError, 422),  # an unknown or draft profile on POST /runs
    (ConfigError, 500),
    (StorageError, 500),
)


def _response(status: int, message: str) -> JSONResponse:
    return JSONResponse(status_code=status, content={"detail": " ".join(message.split())})


def _handler(status: int) -> Handler:
    async def handle(request: Request, exc: Exception) -> JSONResponse:
        return _response(status, str(exc))

    return handle


# Deadlock, serialization failure, lock not available: concurrent changes, not an outage.
_BUSY_SQLSTATES = frozenset({"40P01", "40001", "55P03"})


async def _database_down(request: Request, exc: Exception) -> JSONResponse:
    if getattr(getattr(exc, "orig", None), "sqlstate", None) in _BUSY_SQLSTATES:
        log.warning("database conflict: %s", error_reason(exc))
        return _response(409, "the database was busy with a conflicting change; try again")
    reason = error_reason(exc)
    log.warning("database unavailable: %s", reason)
    return _response(503, f"the database is unavailable: {reason}")


async def _internal(request: Request, exc: Exception) -> JSONResponse:
    log.error("internal error on %s %s", request.method, request.url.path, exc_info=exc)
    return _response(500, "internal error")


def install_error_handlers(app: FastAPI) -> None:
    for exc_type, status in _STATUS:
        app.add_exception_handler(exc_type, _handler(status))
    # Mirrors corelata.worker.execute.DB_ERRORS (not imported: the API does not import the worker).
    app.add_exception_handler(OperationalError, _database_down)
    app.add_exception_handler(InterfaceError, _database_down)
    app.add_exception_handler(Exception, _internal)
```

Starlette picks the handler by walking the exception's MRO, so `InvalidRunStateError` (a `ConflictError`) gets 409 and the table's order does not matter.

```python
"""The FastAPI application (spec §10.1): one ApiContext per process, every /api route behind
current_user except health, openapi.json served behind auth. Copied from Coglossa."""

import contextlib
from collections.abc import AsyncIterator, Callable
from contextlib import AbstractAsyncContextManager
from pathlib import Path
from typing import Any

from fastapi import APIRouter, Depends, FastAPI, Request

import corelata
from corelata.config import CorelataConfig
from corelata.prompts.library import PromptLibrary
from corelata.service import JobQueue
from corelata.storage import build_storage
from corelata.store.db import Database, database_url
from corelata.worker.app import ProcrastinateQueue, open_app
from corelata_api.auth import current_user
from corelata_api.context import ApiContext
from corelata_api.errors import install_error_handlers
from corelata_api.routes import ROUTERS

QueueOpener = Callable[[str], AbstractAsyncContextManager[JobQueue]]


@contextlib.asynccontextmanager
async def procrastinate_queue(url: str) -> AsyncIterator[JobQueue]:
    """The job queue. open_app swaps the connector of procrastinate's shared app, so a process
    opens it once, here for the app's lifetime; any other opening (a worker in the same
    process, in tests) nests inside this one and is closed first."""
    async with open_app(url) as opened:
        yield ProcrastinateQueue(opened)


health = APIRouter(prefix="/api", tags=["system"])
documents = APIRouter()


@documents.get("/openapi.json", include_in_schema=False)
async def get_openapi(request: Request) -> dict[str, Any]:
    return request.app.openapi()


@health.get("/health")
async def get_health() -> dict[str, str]:
    """Liveness: answers without the database and without a signed-in user."""
    return {"status": "ok", "version": corelata.__version__}


def create_app(
    cfg: CorelataConfig, config_path: Path, *, open_queue: QueueOpener = procrastinate_queue
) -> FastAPI:
    @contextlib.asynccontextmanager
    async def lifespan(app: FastAPI) -> AsyncIterator[None]:
        db = Database(database_url(cfg))
        try:
            async with open_queue(db.url) as queue:
                app.state.ctx = ApiContext(
                    cfg=cfg,
                    config_path=config_path,
                    db=db,
                    storage=build_storage(cfg.storage),
                    prompts=PromptLibrary(cfg.prompts_dir),
                    queue=queue,
                )
                yield
        finally:
            await db.dispose()

    app = FastAPI(
        title="Corelata",
        version=corelata.__version__,
        summary="Standards-enforced intelligence report production with a full trace.",
        lifespan=lifespan,
        openapi_url=None,  # served below, behind auth
        docs_url=None,  # Swagger UI loads its assets from a CDN: blank on an air-gapped site
        redoc_url=None,
    )
    install_error_handlers(app)
    app.include_router(health)
    protected = APIRouter(prefix="/api", dependencies=[Depends(current_user)])
    for router in [documents, *ROUTERS]:
        protected.include_router(router)
    app.include_router(protected)
    return app
```

```python
"""Serve the built web app (spec §10.3) from api.web_dir: hashed assets forever, everything else
the index so the SPA router owns the URL. Copied from Coglossa."""

from pathlib import Path

from fastapi import FastAPI, HTTPException
from fastapi.responses import FileResponse
from starlette.staticfiles import StaticFiles
from starlette.types import Scope

IMMUTABLE = "public, max-age=31536000, immutable"


class _Assets(StaticFiles):
    async def get_response(self, path: str, scope: Scope):  # type: ignore[override]
        response = await super().get_response(path, scope)
        response.headers["Cache-Control"] = IMMUTABLE
        return response


def missing_index(web_dir: Path) -> str | None:
    if (web_dir / "index.html").is_file():
        return None
    return (
        f"api.web_dir {web_dir} has no index.html; build the web app (cd web && pnpm build) "
        "or remove api.web_dir"
    )


def mount_web(app: FastAPI, web_dir: Path) -> None:
    """Mount last, after every /api router: the catch-all must not shadow them."""
    root = web_dir.resolve()
    index = root / "index.html"
    if (root / "assets").is_dir():
        app.mount("/assets", _Assets(directory=root / "assets"), name="assets")

    @app.get("/{path:path}", include_in_schema=False)
    async def web_app(path: str) -> FileResponse:
        if path == "api" or path.startswith("api/"):
            raise HTTPException(status_code=404)
        try:
            candidate = (root / path).resolve()
            if path and candidate.is_file() and candidate.is_relative_to(root):
                return FileResponse(candidate)
        except (OSError, ValueError):  # a null byte or an over-long name is not a file
            pass
        return FileResponse(index, headers={"Cache-Control": "no-cache"})
```

```python
"""`corelata-api`: check the installation, then serve. Migrations are not run here (the compose
`migrate` service runs `corelata migrate`); an unmigrated database is refused with the fix."""

import argparse
import sys

import uvicorn

from corelata.config import ConfigError, default_config_path, load_config
from corelata.logs import configure_json_logging, remove_json_logging
from corelata.prompts.check import validate_prompts
from corelata.prompts.library import PromptLibrary
from corelata.storage import StorageError, build_storage
from corelata.store.db import database_url
from corelata.store.migrate import ensure_migrated
from corelata_api.app import create_app
from corelata_api.web import missing_index


def _parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="corelata-api", description="Corelata REST API")
    parser.add_argument("--config", type=Path, default=default_config_path())
    parser.add_argument("--host", default="127.0.0.1")
    parser.add_argument("--port", type=int, default=8080)
    parser.add_argument("--web-dir", type=Path, help="serve the built web app from this directory")
    return parser


def main(argv: list[str] | None = None) -> int:
    args = _parser().parse_args(argv)
    try:
        cfg, warnings = load_config(args.config)
        for warning in warnings:
            print(f"{warning.level}: {warning.message}", file=sys.stderr)
        if args.web_dir is not None:
            cfg = cfg.model_copy(
                update={"api": cfg.api.model_copy(update={"web_dir": args.web_dir.resolve()})}
            )
        validate_prompts(cfg, PromptLibrary(cfg.prompts_dir))
        ensure_migrated(database_url(cfg))
        build_storage(cfg.storage).check_writable()
        if cfg.api.web_dir is not None and (problem := missing_index(cfg.api.web_dir)):
            raise ConfigError(problem)
    except (ConfigError, StorageError) as e:
        print(f"error: {e}", file=sys.stderr)
        return 1
    handler = configure_json_logging()
    try:
        uvicorn.run(create_app(cfg, args.config.resolve()), host=args.host, port=args.port)
    finally:
        remove_json_logging(handler)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
"""Reading an upload within api.max_upload_mb, and naming a download. Copied from Coglossa."""

import re
from urllib.parse import quote

from fastapi import UploadFile

from corelata.storage import display_name
from corelata_api.errors import UploadTooLargeError

CHUNK = 1 << 20  # 1 MiB
_UNSAFE = re.compile(r"[^A-Za-z0-9._ -]")


async def read_upload(file: UploadFile, max_mb: int) -> bytes:
    """The whole upload, or UploadTooLargeError as soon as it passes the limit (nothing is
    stored before this returns)."""
    limit = max_mb * CHUNK
    pieces: list[bytes] = []
    total = 0
    while chunk := await file.read(CHUNK):
        total += len(chunk)
        if total > limit:
            name = display_name(file.filename or "") or "the upload"
            raise UploadTooLargeError(
                f"{name} is larger than the {max_mb} MB upload limit (api.max_upload_mb)"
            )
        pieces.append(chunk)
    return b"".join(pieces)


def content_disposition(filename: str, *, inline: bool = False) -> str:
    """RFC 6266: an ASCII fallback plus the UTF-8 name."""
    fallback = _UNSAFE.sub("_", filename) or "download"
    kind = "inline" if inline else "attachment"
    return f"{kind}; filename=\"{fallback}\"; filename*=UTF-8''{quote(filename, safe='')}"
```

```python
"""Fetch a run's export from a Coglossa deployment (spec §5.3) so an analyst can import a
translation by run id instead of uploading the file. The adapter path after the fetch is the
same as for an upload (`service.add_source(..., coglossa_export=True)`)."""

import os
import re

import httpx

from corelata.config import CoglossaIntegration

_RUN_ID = re.compile(r"^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$")
USER_HEADER = "X-Remote-User"  # Coglossa's trusted header (its default auth.header)


class CoglossaFetchError(Exception):
    """The export could not be fetched; `status` is the HTTP status the API answers with."""

    def __init__(self, message: str, *, status: int) -> None:
        super().__init__(message)
        self.status = status


def _detail(response: httpx.Response) -> str:
    try:
        detail = response.json().get("detail")
    except ValueError:
        detail = None
    text = detail if isinstance(detail, str) else response.text
    return " ".join(text.split())[:200]


class CoglossaClient:
    def __init__(
        self,
        cfg: CoglossaIntegration,
        *,
        transport: httpx.AsyncBaseTransport | None = None,
        timeout_s: float = 30.0,
    ) -> None:
        self.cfg = cfg
        self.transport = transport
        self.timeout_s = timeout_s

    def _headers(self, user: str | None) -> dict[str, str]:
        headers = {"Accept": "application/json"}
        key = os.environ.get(self.cfg.api_key_env) if self.cfg.api_key_env else None
        if key:
            headers["Authorization"] = f"Bearer {key}"
        if user:
            headers[USER_HEADER] = user  # the caller's identity, for Coglossa's own auth
        return headers

    async def fetch_export(self, run_id: str, *, user: str | None) -> bytes:
        """The JSON export of a completed Coglossa run, as bytes for the adapter."""
        if not _RUN_ID.fullmatch(run_id):
            raise CoglossaFetchError(
                "a Coglossa run id is 1-64 letters, digits, dots, dashes or underscores",
                status=422,
            )
        base = self.cfg.base_url.rstrip("/")
        url = f"{base}/api/runs/{run_id}/exports/json"
        try:
            async with httpx.AsyncClient(transport=self.transport, timeout=self.timeout_s) as c:
                response = await c.get(url, headers=self._headers(user))
        except httpx.HTTPError as e:
            raise CoglossaFetchError(
                f"cannot reach Coglossa at {self.cfg.base_url}: {e}", status=502
            ) from e
        if response.status_code == 200:
            return response.content
        if response.status_code == 404:
            raise CoglossaFetchError(f"Coglossa run {run_id} not found", status=404)
        if response.status_code == 409:
            raise CoglossaFetchError(
                f"Coglossa run {run_id} is not complete: {_detail(response)}", status=409
            )
        raise CoglossaFetchError(
            f"Coglossa answered {response.status_code} for run {run_id}: {_detail(response)}",
            status=502,
        )
```

```python
"""Spec §10.1 `GET /runs/{id}/events`: progress as server-sent events. Polls the database at
api.progress_poll_s (LISTEN/NOTIFY later: docs/m3-followups.md). Copied from Coglossa."""

import asyncio
import logging
import uuid
from collections.abc import AsyncIterator

from fastapi import APIRouter
from fastapi.responses import StreamingResponse
from sqlalchemy.exc import InterfaceError, OperationalError

from corelata import service
from corelata.schema import TERMINAL_STATES, RunProgress
from corelata.store.db import error_reason
from corelata.store.runs import NotFoundError
from corelata_api.context import ApiContext, Ctx

log = logging.getLogger("corelata.api")
router = APIRouter(tags=["runs"])

HEARTBEAT_S = 15.0  # comment lines keep proxies from closing a quiet stream


def _event(progress: RunProgress) -> str:
    return f"event: progress\ndata: {progress.model_dump_json()}\n\n"


async def _stream(ctx: ApiContext, run_id: uuid.UUID, first: RunProgress) -> AsyncIterator[str]:
    yield "retry: 3000\n\n"
    yield _event(first)
    last, quiet = first, 0.0
    poll = ctx.cfg.api.progress_poll_s
    while last.state not in TERMINAL_STATES:
        await asyncio.sleep(poll)
        try:
            current = await service.run_progress(ctx.db, run_id)
        except NotFoundError:
            yield "event: deleted\ndata: {}\n\n"
            return
        except (OperationalError, InterfaceError) as e:
            log.warning(
                "progress stream ended: %s", error_reason(e), extra={"run_id": str(run_id)}
            )
            return  # the browser reconnects after `retry`
        if current != last:
            yield _event(current)
            last, quiet = current, 0.0
        else:
            quiet += poll
            if quiet >= HEARTBEAT_S:
                yield ": keep-alive\n\n"
                quiet = 0.0


@router.get(
    "/runs/{run_id}/events",
    response_class=StreamingResponse,
    responses={200: {"content": {"text/event-stream": {}}}},
)
async def run_events(run_id: uuid.UUID, ctx: Ctx) -> StreamingResponse:
    first = await service.run_progress(ctx.db, run_id)  # an unknown run is a plain 404
    return StreamingResponse(
        _stream(ctx, run_id, first),
        media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"},
    )
```

```python
async def complete_queued(api: Api, *, backend=None) -> int:
    """Execute every job the API queued, in order, in this process against the fake backend —
    a deterministic worker for tests of routes that need a finished run. Returns the count."""
    from corelata.prompts.library import PromptLibrary
    from corelata.storage import LocalStorage
    from corelata.testing.fake_backend import FakeBackend
    from corelata.worker.execute import WorkerServices, run_job

    svc = WorkerServices(
        cfg=api.cfg,
        db=api.db,
        storage=LocalStorage(api.cfg.storage.path),
        queue=api.queue,
        backends={"fake": backend or FakeBackend(name="fake")},
        prompts=PromptLibrary(api.cfg.prompts_dir),
    )
    count = 0
    while (job := api.queue.pop()) is not None:
        await run_job(svc, job.task, job.kwargs)
        count += 1
        assert count < 20, "job loop did not settle"
    return count
```

```python
"""Spec §10.1 report and trace views. The report is served from the worker's stored export
(spec §8.4 invariant 5) unless claim ids are requested, which re-renders from the stored record;
every byte here comes from the database and storage, never from a model."""

import asyncio
import tempfile
import uuid
from pathlib import Path
from typing import Literal

from fastapi import APIRouter, Response

from corelata import service
from corelata.exports import OUTPUT_FILES, render_outputs
from corelata.schema import Finding, RunRecord
from corelata.service import InvalidRunStateError
from corelata.standards.schema import ResolvedPack
from corelata.store.runs import NotFoundError
from corelata.trace import ClaimProvenance, RunTrace, claim_provenance, run_trace
from corelata_api.context import ApiContext, Ctx
from corelata_api.uploads import content_disposition

router = APIRouter(tags=["reports"])

DOCX = "application/vnd.openxmlformats-officedocument.wordprocessingml.document"
MEDIA = {
    "json": "application/json",
    "md": "text/markdown; charset=utf-8",
    "html": "text/html; charset=utf-8",
    "docx": DOCX,
}
Format = Literal["json", "md", "html", "docx"]
ExportName = Literal["trace.json", "gate.json", "report.json", "report.md", "report.html", "report.docx"]
assert set(ExportName.__args__) == set(OUTPUT_FILES)  # the two lists are one list


def _file(
    content: bytes, *, media: str, filename: str, attachment: bool, sha256: str | None = None
) -> Response:
    headers = {"Content-Disposition": content_disposition(filename, inline=not attachment)}
    return Response(content=content, media_type=media, headers=headers)


async def _record_with_report(ctx: ApiContext, run_id: uuid.UUID) -> RunRecord:
    record = await service.get_run_record(ctx.db, run_id)
    if record.report is None:
        raise InvalidRunStateError(f"run {run_id} has no report (state {record.state.value})")
    return record


def _render(record: RunRecord, fmt: str, *, with_claim_ids: bool, reference: bytes | None) -> bytes:
    """One export from the stored record, off the event loop; the DOCX reads the run's stored
    reference document from a temporary file."""
    pack = ResolvedPack.model_validate(record.pack_snapshot)
    with tempfile.TemporaryDirectory() as tmp:
        path: Path | None = None
        if fmt == "docx" and reference is not None:
            path = Path(tmp) / "reference.docx"
            path.write_bytes(reference)
        out = render_outputs(
            record,
            pack,
            with_claim_ids=with_claim_ids,
            docx_claim_ids=with_claim_ids,
            docx_reference=path,
            formats=(fmt,),
        )[f"report.{fmt}"]
    return out if isinstance(out, bytes) else out.encode("utf-8")


@router.get(
    "/runs/{run_id}/report",
    response_class=Response,
    responses={200: {"content": {media: {} for media in MEDIA.values()}}},
)
async def get_report(
    run_id: uuid.UUID,
    ctx: Ctx,
    format: Format = "html",
    with_claim_ids: bool = False,
    download: bool = False,
) -> Response:
    """The delivered report. Without claim ids: the worker's stored file, byte for byte. With
    them: re-rendered from the stored record (spec §9). 409 while the run has no report."""
    record = await _record_with_report(ctx, run_id)
    content: bytes | None = None
    if not with_claim_ids:
        content = await service.stored_export(ctx.db, ctx.storage, run_id, f"report.{format}")
        if content is None:
            progress = await service.run_progress(ctx.db, run_id)
            if format == "docx" and progress.export_error:
                raise InvalidRunStateError(progress.export_error)
    if content is None:
        reference = (
            await service.reference_document(ctx.db, ctx.storage, run_id)
            if format == "docx"
            else None
        )
        content = await asyncio.to_thread(
            _render, record, format, with_claim_ids=with_claim_ids, reference=reference
        )
    return _file(
        content,
        media=MEDIA[format],
        filename=f"report-{str(run_id)[:8]}.{format}",
        attachment=download or format == "docx",
    )


@router.get(
    "/runs/{run_id}/exports/{name}",
    response_class=Response,
    responses={200: {"content": {"application/json": {}, "text/markdown": {}, "text/html": {}, DOCX: {}}}},
)
async def get_export(run_id: uuid.UUID, name: ExportName, ctx: Ctx) -> Response:
    """A file the worker stored for the run, as stored (the trace JSON download among them)."""
    content = await service.stored_export(ctx.db, ctx.storage, run_id, name)
    if content is None:
        raise NotFoundError(f"run {run_id} has no stored export {name}")
    stem, ext = name.rsplit(".", 1)
```
