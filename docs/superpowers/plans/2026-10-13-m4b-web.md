# Corelata M4b: Web Review UI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver spec §14 M4b: the three web screens of spec §10.3 — **New run** (project, sources, value statement with "Suggest value", profile, iterations, Start), **Progress** (stage timeline over SSE, iterations, token usage, cancel) and **Review** (rendered report with claim highlighting; Provenance, Audit, Process and Sources tabs; Accept, Return with note, downloads) — as a React single-page app served by the M4a API, with Vitest at 95% and Playwright journeys against the fake model and a throwaway database.

**Architecture:** `web/` is a Vite + React 19 + TypeScript app with a typed `openapi-fetch` client generated from `schema/openapi.json`; data flows through TanStack Query hooks (one module per resource, key factories, `unwrap` → `ApiError`), progress arrives over an `EventSource` hook that patches the query cache and closes on a terminal state (polling fallback), and the report is shown in a same-origin iframe the page writes into, so the report's own stylesheet cannot leak and the page can highlight `data-claim-ids` elements. The shell (client wrapper, providers, router, layout, error pages, test harness, Playwright config, devstack) is copied from Coglossa's `web/` and `api/devstack.py` (spec §4.3) with the product name parameterised; Coglossa's translation screens are replaced by Corelata's three.

- Product name parameterised (spec §4.3): package `corelata-web`, title `Corelata`, brand text `Corelata`, env `CORELATA_TEST_DATABASE_URL` / `CORELATA_DATABASE_URL`, devstack temp prefix `corelata-dev-`.

## Review Focus

1. **The report's own stylesheet must not restyle the app, and highlighting must work on reports whose paragraphs carry several claim ids** (`data-claim-ids="c1 c3"`): selecting `c3` highlights that paragraph; selecting a claim no element carries highlights nothing and shows no error; clicking a highlighted paragraph in the frame selects its first claim. (Task 7: `test_report_frame_highlights_and_selects`.)
2. **A run that ends while the Progress screen is open** gets one terminal event, the stream is closed (no reconnect loop), the timeline shows every stage done and the "Review the report" link appears; a `deleted` event ends the stream and the page shows the 404 error; a browser without `EventSource` polls every 3 s and stops polling at a terminal state. (Task 6: `test_terminal_event_closes_the_stream_and_links_to_review`, `test_deleted_event_shows_not_found`; Task 3: `pollInterval` tests.)
3. **"Suggest value"** polls the discovery until it completes or fails, shows candidates with evidence, fills the statement when one is chosen, and shows the API's error (and stops polling) when the discovery fails or the request is rejected (no sources selected → the button is disabled with a hint). (Task 5: `test_suggest_value_fills_the_statement`, `test_failed_discovery_shows_the_error`.)
4. **Upload rejections** (413 too large, 422 unsupported type or empty file, 404 project gone) show the API's `detail` inline, keep the rest of the form, and reset the file input so the same file can be chosen again; a successful upload appears in the source list already selected for the run. (Task 4: `test_upload_rejection_shows_detail`, `test_upload_adds_and_selects_the_source`.)
5. **Return with an empty note is impossible** (button disabled, hint shown); a successful return navigates to the child run's Progress screen; Accept shows "Accepted" and disables both actions; a 409 (run no longer completed) shows the API's detail. (Task 7: `test_return_requires_a_note_and_opens_the_child`, `test_accept_and_conflict`.)

`web/src/api/client.ts`:

```ts
import createClient from "openapi-fetch";
import type { paths } from "./schema";
import type { ExportName, ReportFormat } from "./types";

// openapi-fetch keeps the fetch it is given; a late-bound wrapper lets tests (msw) patch fetch.
const lateFetch: typeof fetch = (input, init) => globalThis.fetch(input, init);

// The app always talks to the server it was loaded from. location.origin rather than "" because
// Node's fetch (tests) refuses relative URLs; in a browser the two are the same.
export const client = createClient<paths>({ baseUrl: location.origin, fetch: lateFetch });

export const NETWORK_ERROR =
  "The Corelata server could not be reached; check that it is running and try again.";

export class ApiError extends Error {
  constructor(
    readonly status: number,
    message: string,
  ) {
    super(message);
    this.name = "ApiError";
  }
}

type ValidationItem = { loc?: (string | number)[]; msg?: string };
const PLACES = new Set(["body", "query", "path"]);

/** The one line to show for a failed request: the API's `detail` (spec: errors are one line). */
export function errorText(status: number, body: unknown): string {
  const detail = (body as { detail?: unknown } | null | undefined)?.detail;
  if (typeof detail === "string" && detail) return detail;
  if (Array.isArray(detail) && detail.length > 0) {
    const first = detail[0] as ValidationItem;
    const field = (first.loc ?? []).filter((part) => !PLACES.has(String(part))).join(".");
    return field ? `${field}: ${first.msg}` : String(first.msg);
  }
  return `The server answered ${status} without an explanation.`;
}

/** The data of an API call, or an ApiError with the message to show. */
export async function unwrap<T>(
  call: Promise<{ data?: T; error?: unknown; response: Response }>,
): Promise<T> {
  let result: { data?: T; error?: unknown; response: Response };
  try {
    result = await call;
  } catch {
    throw new ApiError(0, NETWORK_ERROR);
  }
  if (!result.response.ok) {
    throw new ApiError(result.response.status, errorText(result.response.status, result.error));
  }
  return result.data as T;
}

/** Text or bytes from a route the typed client types as a file: the report and the exports. */
export async function unwrapText(url: string): Promise<string> {
  let response: Response;
  try {
    response = await globalThis.fetch(url);
  } catch {
    throw new ApiError(0, NETWORK_ERROR);
  }
  if (!response.ok) {
    let body: unknown = null;
    try {
      body = await response.json();
    } catch {
      body = null;
    }
    throw new ApiError(response.status, errorText(response.status, body));
  }
  return response.text();
}

/** URLs the browser loads itself (an EventSource, a download link, the report frame). */
export function eventsUrl(runId: string): string {
  return `/api/runs/${encodeURIComponent(runId)}/events`;
}

export function reportUrl(
  runId: string,
  format: ReportFormat,
  opts: { claimIds?: boolean; download?: boolean } = {},
): string {
  const params = new URLSearchParams({ format });
  if (opts.claimIds) params.set("with_claim_ids", "true");
  if (opts.download) params.set("download", "true");
  return `/api/runs/${encodeURIComponent(runId)}/report?${params}`;
```

```ts
export function formatDuration(ms: number): string {
```

```tsx
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import type { ReactNode } from "react";
import { ApiError } from "./api/client";

/** A 4xx will not change on a retry; a network error or 5xx might, once. */
export function retryOnce(count: number, error: unknown): boolean {
  if (error instanceof ApiError && error.status >= 400 && error.status < 500) return false;
  return count < 1;
}

export function makeQueryClient({ retry = true }: { retry?: boolean } = {}): QueryClient {
  return new QueryClient({
    defaultOptions: {
      queries: { retry: retry ? retryOnce : false, refetchOnWindowFocus: false },
      mutations: { retry: false },
    },
  });
}

export function Providers({ client, children }: { client: QueryClient; children: ReactNode }) {
```

```ts
import type { EventSourceLike } from "../api/events";

/** A stand-in for the browser's EventSource (jsdom has none). */
export class FakeEventSource implements EventSourceLike {
  static instances: FakeEventSource[] = [];
  listeners = new Map<string, (event: MessageEvent<string>) => void>();
  closed = false;
  readyState = 1;

  constructor(readonly url: string) {
    FakeEventSource.instances.push(this);
  }

  addEventListener(type: string, listener: (event: MessageEvent<string>) => void) {
    this.listeners.set(type, listener);
  }

  close() {
    this.closed = true;
  }

  emit(type: string, data: unknown) {
    this.listeners.get(type)?.({ data: JSON.stringify(data) } as MessageEvent<string>);
  }

  /** The browser gave up (readyState CLOSED) and fires `error`. */
  fail() {
    this.readyState = 2;
    this.listeners.get("error")?.({ data: "" } as MessageEvent<string>);
  }

  static last(): FakeEventSource {
    const last = FakeEventSource.instances.at(-1);
    if (!last) throw new Error("no EventSource was opened");
    return last;
  }
}
```

```ts
import { useQueryClient } from "@tanstack/react-query";
import { useEffect } from "react";
import { isTerminal } from "../lib/format";
import { eventsUrl } from "./client";
import { runKeys } from "./runs";
import type { RunProgress } from "./types";

export type EventSourceLike = {
  readonly readyState: number;
  addEventListener(type: string, listener: (event: MessageEvent<string>) => void): void;
  close(): void;
};
export type EventSourceFactory = (url: string) => EventSourceLike;

const EVENT_SOURCE_CLOSED = 2;

let override: EventSourceFactory | null | undefined;

/** Tests replace the browser's EventSource; `undefined` restores it, `null` turns it off. */
export function setEventSourceFactory(factory?: EventSourceFactory | null): void {
  override = factory;
}

function factory(): EventSourceFactory | null {
  if (override !== undefined) return override;
  if (typeof EventSource === "undefined") return null;
  return (url) => new EventSource(url);
}

export function liveUpdatesAvailable(): boolean {
  return factory() !== null;
}

/** Spec §10.3 Progress: follow a run over server-sent events while it runs. The server closes
 * the stream after the terminal event; the client closes too, or a browser would reconnect
 * forever (docs/m4a-followups.md). */
export function useRunEvents(runId: string, active: boolean, onStreamFailed?: () => void): void {
  const queryClient = useQueryClient();
  useEffect(() => {
    const open = factory();
    if (!active || open === null) return;
    const source = open(eventsUrl(runId));
    source.addEventListener("progress", (event) => {
      const progress = JSON.parse(event.data) as RunProgress;
      queryClient.setQueryData<RunProgress>(runKeys.one(runId), progress);
      if (isTerminal(progress.state)) source.close();
    });
    source.addEventListener("deleted", () => {
      source.close();
      void queryClient.invalidateQueries({ queryKey: runKeys.one(runId) });
    });
    // The browser reconnects by itself unless it gave up (readyState CLOSED, e.g. a 502):
    // then the page falls back to polling.
    source.addEventListener("error", () => {
      if (source.readyState !== EVENT_SOURCE_CLOSED) return;
      source.close();
      onStreamFailed?.();
    });
    return () => source.close();
  }, [runId, active, queryClient, onStreamFailed]);
}
```

```tsx
import { useId, useRef, useState } from "react";
import { useUploadSource } from "../../api/projects";
import type { SourceKind, SourceView } from "../../api/types";
import { ErrorMessage } from "../../components/ErrorMessage";

export function UploadSource({
  projectId,
  maxUploadMb,
  onAdded,
}: {
  projectId: string;
  maxUploadMb: number;
  onAdded: (added: SourceView[]) => void;
}) {
  const upload = useUploadSource(projectId);
  const [file, setFile] = useState<File | null>(null);
  const [kind, setKind] = useState<SourceKind>("file");
  const input = useRef<HTMLInputElement>(null);
  const fileId = useId();
  const kindId = useId();

  function reset() {
    setFile(null);
    if (input.current) input.current.value = "";
  }

  function submit(event: React.FormEvent) {
    event.preventDefault();
    if (!file) return;
    upload.mutate(
      { file, kind },
      {
        onSuccess: (added) => {
          reset();
          onAdded(added);
        },
        onError: reset, // the same file can be chosen again
      },
    );
  }

  return (
    <form aria-label="Add a source" className="row" onSubmit={submit}>
      <label htmlFor={fileId} className="muted">
        Add a file
      </label>
      <input
        id={fileId}
        ref={input}
        type="file"
        accept=".docx,.pdf,.txt,.md,.html,.htm,.json,.csv"
        onChange={(event) => setFile(event.target.files?.[0] ?? null)}
      />
      <label htmlFor={kindId} className="muted">
        Kind
      </label>
      <select id={kindId} value={kind} onChange={(event) => setKind(event.target.value as SourceKind)}>
        <option value="file">Document</option>
        <option value="coglossa_export">Coglossa export</option>
```

```tsx
import { useEffect, useRef, type ReactNode } from "react";

/** A native modal dialog. Focus moves to the first button when it opens and back to whatever
 * had it when it closes (the browser does both for showModal/close). */
export function ConfirmDialog({
  open,
  title,
  children,
  confirmLabel,
  cancelLabel = "Keep going",
  danger = false,
  busy = false,
  onConfirm,
  onCancel,
}: {
  open: boolean;
  title: string;
  children?: ReactNode;
  confirmLabel: string;
  cancelLabel?: string;
  danger?: boolean;
  busy?: boolean;
  onConfirm: () => void;
  onCancel: () => void;
}) {
  const ref = useRef<HTMLDialogElement>(null);
  const opener = useRef<Element | null>(null);
  useEffect(() => {
    const dialog = ref.current;
    if (!dialog) return;
    if (open && !dialog.open) {
      opener.current = document.activeElement;
      dialog.showModal();
      dialog.querySelector<HTMLElement>("button")?.focus();
    } else if (!open && dialog.open) {
      dialog.close();
      (opener.current as HTMLElement | null)?.focus?.();
    }
  }, [open]);
  if (!open) return null;
  return (
    <dialog ref={ref} aria-labelledby="confirm-title" onCancel={onCancel} onClose={onCancel}>
      <h2 id="confirm-title">{title}</h2>
      {children}
      <div className="row">
        <button type="button" className="secondary" onClick={onCancel} disabled={busy}>
          {cancelLabel}
        </button>
        <button type="button" className={danger ? "danger" : ""} onClick={onConfirm} disabled={busy}>
          {confirmLabel}
        </button>
      </div>
    </dialog>
  );
}
```

Note: returning `null` when closed removes the element, so the close effect must run before unmount — keep the dialog mounted while `open` is true and let the parent flip `open` to false; the effect's `else` branch closes it and restores focus before the next render removes the node. If the restore proves flaky in jsdom, call `opener.current.focus()` in `onCancel`/`onConfirm` handlers of the parent instead and say so in the report.

```tsx
import type { RunProgress, StageResult } from "../../api/types";
import { durationBetween, formatDuration, isTerminal, STAGES, STATE_LABELS, type Stage } from "../../lib/format";

export type RowStatus = "done" | "failed" | "running" | "pending";
export type TimelineRow = { stage: Stage; label: string; status: RowStatus; attempts: StageResult[] };

/** One row per pipeline stage (spec §7.2). A stage is running when it is the run's state; done
 * when its last attempt succeeded; failed when its last attempt failed; pending otherwise. */
export function timelineRows(progress: RunProgress): TimelineRow[] {
  return STAGES.map((stage) => {
    const attempts = progress.stages.filter((s) => s.stage === stage);
    const last = attempts.at(-1);
    let status: RowStatus = "pending";
    if (progress.state === stage && !isTerminal(progress.state)) status = "running";
    else if (last) status = last.ok ? "done" : "failed";
    return { stage, label: STATE_LABELS[stage], status, attempts };
  });
}

function describe(row: TimelineRow, progress: RunProgress): string {
  const last = row.attempts.at(-1);
  if (row.status === "running") {
    const iteration = progress.iteration + 1;
    return progress.iteration > 0 ? `iteration ${iteration} running` : "running";
  }
  if (!last) return "";
  const ms = durationBetween(last.started_at, last.finished_at);
  const parts = [ms === null ? "" : formatDuration(ms)];
  if (row.attempts.length > 1) parts.push(`${row.attempts.length} iterations`);
  if (row.status === "failed" && last.error) parts.push(last.error);
  return parts.filter(Boolean).join(" · ");
}

export function StageTimeline({ progress }: { progress: RunProgress }) {
  return (
    <ol aria-label="Stages" className="timeline">
      {timelineRows(progress).map((row) => (
        <li key={row.stage} data-status={row.status}>
          <span className="stage">{row.label}</span>
          <span className="muted">{describe(row, progress)}</span>
        </li>
      ))}
    </ol>
  );
}
```

```tsx
import type { KeyboardEvent, ReactNode } from "react";

export type Tab = { id: string; label: string };

/** WAI-ARIA tabs: one tablist, arrow keys move and select, one panel shown. */
export function Tabs({
  label,
  tabs,
  active,
  onChange,
  children,
}: {
  label: string;
  tabs: Tab[];
  active: string;
  onChange: (id: string) => void;
  children: (active: string) => ReactNode;
}) {
  const index = Math.max(0, tabs.findIndex((t) => t.id === active));

  function onKeyDown(event: KeyboardEvent<HTMLDivElement>) {
    const moves: Record<string, number> = {
      ArrowRight: (index + 1) % tabs.length,
      ArrowLeft: (index - 1 + tabs.length) % tabs.length,
      Home: 0,
      End: tabs.length - 1,
    };
    const next = moves[event.key];
    if (next === undefined) return;
    event.preventDefault();
    const tab = tabs[next]!;
    onChange(tab.id);
    (event.currentTarget.querySelector(`#tab-${tab.id}`) as HTMLElement | null)?.focus();
  }

  const current = tabs[index]!;
  return (
    <div className="tabs-root">
      <div role="tablist" aria-label={label} className="tabs" onKeyDown={onKeyDown}>
        {tabs.map((tab, i) => (
          <button
            key={tab.id}
            id={`tab-${tab.id}`}
            role="tab"
            type="button"
            aria-selected={i === index}
            aria-controls={`panel-${tab.id}`}
            tabIndex={i === index ? 0 : -1}
            onClick={() => onChange(tab.id)}
          >
            {tab.label}
          </button>
        ))}
      </div>
      <div role="tabpanel" id={`panel-${current.id}`} aria-labelledby={`tab-${current.id}`} className="tabpanel">
        {children(current.id)}
      </div>
    </div>
  );
}
```

```tsx
 * inside, no script runs, and the page can mark the elements that cite the selected claim. */
export function ReportFrame({
  html,
  selectedClaim,
  onSelectClaim,
}: {
  html: string;
  selectedClaim: string | null;
  onSelectClaim: (claimId: string) => void;
}) {
  const frame = useRef<HTMLIFrameElement>(null);
  const select = useRef(onSelectClaim);
  select.current = onSelectClaim;

  // Write the document once per report; wire a click handler for cited paragraphs.
  useEffect(() => {
    const doc = frame.current?.contentDocument;
    if (!doc) return;
    doc.open();
    doc.write(html);
    doc.close();
    const style = doc.createElement("style");
    style.textContent = HIGHLIGHT_CSS;
    doc.head.appendChild(style);
    const onClick = (event: Event) => {
      const target = (event.target as Element | null)?.closest("[data-claim-ids]");
      const [first] = splitIds(target?.getAttribute("data-claim-ids"));
      if (first) select.current(first);
    };
    doc.addEventListener("click", onClick);
    return () => doc.removeEventListener("click", onClick);
  }, [html]);

  // Highlight follows the selection.
  useEffect(() => {
    const doc = frame.current?.contentDocument;
    if (!doc) return;
    for (const el of doc.querySelectorAll(".corelata-highlight")) el.classList.remove("corelata-highlight");
    if (!selectedClaim) return;
    const marked = doc.querySelectorAll(`[data-claim-ids~="${CSS.escape(selectedClaim)}"]`);
    for (const el of marked) el.classList.add("corelata-highlight");
    marked[0]?.scrollIntoView?.({ block: "center" });
  }, [selectedClaim, html]);

  return <iframe ref={frame} title="Report" className="report-frame" sandbox="allow-same-origin" />;
}
```

```tsx
import { useResolvedPack } from "../../api/packs";
import { useFindings, useTrace } from "../../api/reports";
import type { Finding, Rule } from "../../api/types";
import { ErrorMessage } from "../../components/ErrorMessage";
import { Loading } from "../../components/Loading";

export type AuditRow = {
  ruleId: string;
  title: string;
  advisory: boolean;
  latest: Finding;
  history: Finding[]; // by iteration
};

/** One row per rule (spec §10.3 Audit tab): the last iteration's finding, with the history. */
export function auditRows(findings: Finding[], rules: Rule[] | undefined): AuditRow[] {
  const byRule = new Map<string, Finding[]>();
  for (const f of findings) byRule.set(f.rule_id, [...(byRule.get(f.rule_id) ?? []), f]);
  const ruleIndex = new Map((rules ?? []).map((r) => [r.id, r]));
  const order = (id: string) => {
    const i = (rules ?? []).findIndex((r) => r.id === id);
    return i === -1 ? Number.MAX_SAFE_INTEGER : i;
  };
  return [...byRule.entries()]
    .sort(([a], [b]) => order(a) - order(b) || a.localeCompare(b))
    .map(([ruleId, list]) => {
      const history = [...list].sort((a, b) => a.iteration - b.iteration);
      const rule = ruleIndex.get(ruleId);
      return {
        ruleId,
        title: rule?.title ?? ruleId,
        advisory: rule?.checkability === "advisory",
        latest: history.at(-1)!,
        history,
      };
    });
}

function RuleTable({ label, rows }: { label: string; rows: AuditRow[] }) {
  if (rows.length === 0) return null;
  return (

      <thead>

          <th>Rule</th>
          <th>Verdict</th>
          <th>Severity</th>
          <th>Evidence</th>
          <th>History</th>
        </tr>
      </thead>
      <tbody>
        {rows.map((r) => (
          <tr key={r.ruleId}>
            <td>
              <strong>{r.title}</strong>
              <br />

export function AuditTab({ runId }: { runId: string }) {

          <RuleTable label="Verifiable rules" rows={rows.filter((r) => !r.advisory)} />

        </>
```

```python
"""A complete local Corelata for a browser: a throwaway database, the fake model server, a
worker, and the API serving the built web app. `make dev-stack` runs it for development (with
`pnpm dev` for live reloading); the Playwright journeys start it as their web server. Ctrl+C (or
SIGTERM) stops everything and drops the database. Copied from Coglossa without the scorer."""

import argparse
import contextlib
import os
import shutil
import signal
import socket
import subprocess
import sys
import tempfile
import time
import urllib.request
from pathlib import Path
from types import FrameType

import yaml
from corelata.store.migrate import upgrade
from corelata.testing.postgres import TEST_DB_ENV, create_test_database, drop_test_database

CORELATA = [sys.executable, "-c", "import sys; from corelata.cli import main; sys.exit(main())"]
API = [sys.executable, "-c", "import sys; from corelata_api.main import main; sys.exit(main())"]


def free_port() -> int:
    with socket.socket() as s:
        s.bind(("127.0.0.1", 0))
        return s.getsockname()[1]


def wait_for(url: str, timeout_s: float, procs: list[subprocess.Popen[bytes]]) -> None:
    deadline = time.monotonic() + timeout_s
    while time.monotonic() < deadline:
        for p in procs:
            if p.poll() is not None:
                raise RuntimeError(f"{p.args} exited with {p.returncode}")
        with (
            contextlib.suppress(OSError),
            urllib.request.urlopen(url, timeout=1) as response,  # noqa: S310 (local URL)
        ):
            if response.status == 200:
                return
        time.sleep(0.2)
    raise RuntimeError(f"{url} did not answer within {timeout_s:.0f} s")


def config(work: Path, llm_port: int, web_dir: Path | None) -> dict:
    api: dict = {"progress_poll_s": 0.2}
    if web_dir is not None:
        api["web_dir"] = str(web_dir.resolve())
    return {
        "backends": {"local": {"base_url": f"http://127.0.0.1:{llm_port}/v1", "max_concurrency": 4}},
        "models": {"m1": {"backend": "local", "name": "fake-model", "context_window": 32768}},
        "roles": {role: {"model": "m1"} for role in ("gate", "writer", "conveyor", "auditor")},
        "storage": {"path": str(work / "files")},
        "worker": {"concurrency": 2, "stalled_after_s": 60},
        "api": api,
    }


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--host", default="127.0.0.1")
    parser.add_argument("--port", type=int, default=8080)
    parser.add_argument("--web-dir", type=Path, help="the built web app (web/dist)")
    args = parser.parse_args(argv)
    admin = os.environ.get(TEST_DB_ENV)
    if not admin:
        print(f"error: set {TEST_DB_ENV} to a Postgres admin URL (make dev-stack does)", file=sys.stderr)
        return 1
    url = create_test_database(admin)
    work = Path(tempfile.mkdtemp(prefix="corelata-dev-"))
    procs: list[subprocess.Popen[bytes]] = []

    def stop(signum: int | None = None, frame: FrameType | None = None) -> None:
        # Ignore further signals so that a repeated one cannot interrupt the cleanup.
        signal.signal(signal.SIGINT, signal.SIG_IGN)
        signal.signal(signal.SIGTERM, signal.SIG_IGN)
        raise KeyboardInterrupt

    signal.signal(signal.SIGINT, stop)
    signal.signal(signal.SIGTERM, stop)
    try:
        upgrade(url)
        llm = free_port()
        path = work / "corelata.yaml"
        path.write_text(yaml.safe_dump(config(work, llm, args.web_dir)), encoding="utf-8")
        env = {**os.environ, "CORELATA_DATABASE_URL": url}
        procs.append(
            subprocess.Popen([*CORELATA, "fake-openai", "--host", "127.0.0.1", "--port", str(llm)], env=env)
        )
        procs.append(subprocess.Popen([*CORELATA, "worker", "--config", str(path)], env=env))
        procs.append(
            subprocess.Popen(
                [*API, "--config", str(path), "--host", args.host, "--port", str(args.port)], env=env
            )
        )
        wait_for(f"http://{args.host}:{args.port}/api/health", 60, procs)
        address = f"http://{args.host}:{args.port}"
        if args.web_dir is not None:
            print(f"Corelata is running at {address} (Ctrl+C to stop)", flush=True)
        else:  # the API alone: the app comes from `pnpm dev`, which forwards /api here
            print(
                f"The Corelata API is running at {address}; for the web app, run `pnpm dev` in "
                "web/ and open the address it prints (Ctrl+C to stop)",
                flush=True,
            )
        while all(p.poll() is None for p in procs):
            time.sleep(0.5)
        print("error: a service stopped; shutting down", file=sys.stderr)
        return 1
    except KeyboardInterrupt:
        return 0
    finally:
        for p in procs:
            p.terminate()
        for p in procs:
            with contextlib.suppress(subprocess.TimeoutExpired):
                p.wait(timeout=10)
            if p.poll() is None:
                p.kill()
        drop_test_database(admin, url)
        shutil.rmtree(work, ignore_errors=True)


if __name__ == "__main__":
    sys.exit(main())
```
